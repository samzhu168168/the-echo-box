# The Echo Box SEO/GEO Baseline

Production baseline captured before the September 2026 content sprint. Source of truth: the live Production responses and the 17 URLs in `sitemap.xml`.

## Technical baseline

- Production entry: `https://www.my-echo-box.com/`
- Deployment output: `dist/`, generated by `scripts/build_dist.js`
- `robots.txt`: HTTP 200; normal crawling allowed; sitemap declared; Googlebot and Bingbot are not blocked.
- `sitemap.xml`: HTTP 200; 17 URLs before this sprint.
- Canonicals: self-referencing across all 17 sitemap URLs.
- Guide metadata: unique title, description, OpenGraph, X Card, Article and BreadcrumbList on all 8 existing Guides.
- Trust pages: About, Safety, Privacy, Editorial Policy, Sources and Contact exist.
- Gumroad source of truth: `commerce-config.js` → `https://samzhu168.gumroad.com/l/echo-box-30-day-no-contact-reset-kit` at `$9.99`.
- Analytics: existing local event store plus Plausible integration; no private message property is permitted.
- IndexNow: existing `scripts/indexnow-submit.mjs` and Production key file.
- `llms.txt`: not present. No file will be added for this sprint.
